**Building an LLM From Scratch | A Learning Journey**

I'm starting a hands-on project to build a small GPT-style language model from scratch, with the goal of understanding how language models work from their mathematical foundations to production inference.

As a Computer Engineering graduate student at the University of Central Florida, I'm currently studying machine learning, computer architecture, and parallel computing.

I want to connect these concepts through practical implementation rather than treating them as separate subjects.

My plan is to progressively implement tokenization, embeddings, self-attention, Transformer blocks, model training, and eventually GPU inference and serving optimizations.

I'll document each completed milestone, including the implementation, experiments, challenges, and lessons learned.

The goal isn't to build the biggest model. It's to understand the systems behind modern LLMs.
